# Featured Projects 🚀

### 🖋️ [DukeQuill](https://github.com/changoloco066/DukeQuill)
Spanish spell-checker & grammar correction ecosystem — custom lexer, Hunspell dictionary integration, Damerau-Levenshtein suggestions, LanguageTool morphological analysis, and a 7-rule grammar engine. Swing desktop app + Spring Boot REST API + web frontend with Anime.js.<br>
`Java` `Spring Boot` `Swing`

### 📱 [TaEisHeauton](https://github.com/changoloco066/TaEisHeauton)
Android widget displaying a random personal reflection daily, named after the original Greek title of Marcus Aurelius' *Meditations*. Room + WorkManager + custom 3-state parser.<br>
`Java` `Android` `Room`

### 🎓 qr-asistencia
QR-based attendance web app built for a university professor — full three-phase feature set, live in production.<br>
`Flask` `Neon PostgreSQL` `Vercel`

### 🐦 [Who's That Bird?](https://github.com/changoloco066/whos-that-bird)
Bird identification app running entirely in-browser using tau-Prolog, expanded from a Formal Languages & Automata course project into a full frontend with a Mexican ecosystem color palette.<br>
`Prolog` `JavaScript`

### 🔧 [MiniLang Compiler](https://github.com/changoloco066/MiniLang-Compiler)
Recursive descent compiler with panic-mode error recovery, symbol table, and syntax tree visualization, built in Java/Swing.<br>
`Java` `Swing`

### 📦 Inventory Management System *(team project, private repo)*
JavaFX desktop app connecting to SQL Server via JDBC, with PDF export via iText.<br>
`Java` `JavaFX` `SQL Server` `JDBC`
